# I — экспериментальный язык программирования

> Документация составлена по состоянию исходного кода репозитория `I-on-CPP-master` (22 ноября 2026 года). Проект находится на ранней стадии разработки: описанные ниже возможности относятся к текущей реализации, а не к окончательному дизайну языка.

## 1. О проекте

**I** — экспериментальный интерпретируемый язык программирования, реализация которого написана на C++. Репозиторий содержит базовую цепочку обработки исходного текста: лексический анализ, передачу токенов парсеру, обработку инструкций и хранение переменных.

Текущая реализация — прототип. Она демонстрирует базовые операции с переменными, арифметические выражения, логические значения, ввод и вывод. Некоторые типы и конструкции уже обозначены во внутренних структурах, но ещё не имеют полноценной реализации.

## 2. Текущие возможности

| Возможность | Состояние в исходном коде |
|---|---|
| Объявление `int` | Реализовано |
| Объявление `bool` | Реализовано |
| Присваивание переменным | Реализовано для `int` и `bool` |
| Арифметика `+`, `-`, `*`, `/` | Используется при вычислении целочисленных выражений |
| Скобки и приоритет арифметических операций | Поддерживаются отдельным рекурсивным парсером выражений |
| Вывод через `cout(...)` | Реализован |
| Ввод через `cin` | Реализован в обработчиках целых и логических переменных |
| `float`, `double`, `char`, строки как типы переменных | Полноценная работа не реализована |
| Условия и циклы | Распознавание отдельных ключевых слов есть, полноценная обработка не завершена |
| AST | Есть заготовки структур, но рабочее построение дерева не показано |
| Подключение файлов | В этой версии репозитория не реализовано |

## 3. Синтаксис

Инструкции в примерах завершаются точкой с запятой `;`.

### 3.1. Объявление переменных

Для целых чисел:

```i
age.int = 16;
```

Для логических значений:

```i
enabled.bool = true;
```

В текущем парсере тип записывается после имени переменной через точку. Для `int` и `bool` предусмотрены обработчики регистрации переменных.

Также в коде встречается обработка объявления без начального значения, однако из-за ограничений текущего парсера надёжнее пока задавать значение явно.

### 3.2. Присваивание

```i
age = 17;
enabled = false;
```

Присваивание выполняется для уже зарегистрированных переменных типов `int` и `bool`.

### 3.3. Арифметические выражения

Целочисленные выражения могут содержать:

- `+` — сложение;
- `-` — вычитание;
- `*` — умножение;
- `/` — деление;
- `(` и `)` — группировку выражений.

Пример:

```i
result.int = (10 + 5) * 2;
```

Для вычисления выражений используется отдельный рекурсивный парсер. Он учитывает приоритет умножения и деления над сложением и вычитанием, а также унарные `+` и `-`.

Результат выражения при сохранении в `int` преобразуется к целому числу.

### 3.4. Вывод

```i
cout("Hello, I!");
```

Можно передать имя переменной:

```i
score.int = 100;
cout(score);
```

В текущем обработчике вывод переменной предусмотрен для `int` и `bool`. Логические значения преобразуются в строковое представление C++ (`0` или `1`).

### 3.5. Ввод

В качестве источника значения обработчики переменных принимают ключевое слово `cin`:

```i
number.int = cin;
```

```i
flag.bool = cin;
```

Ввод выполняется средствами стандартного потока `std::cin`. Перед чтением программа сбрасывает накопленный буфер вывода в консоль.

## 4. Пример программы

```i
name.bool = false;
cout(name);

name = true;
cout(name);
```

Пример показывает объявление логической переменной, вывод её значения и последующее изменение.

В репозитории `example.i` сейчас находится именно такой по смыслу тест: объявление `ff.bool`, вывод, присваивание `true` и повторный вывод.

## 5. Как устроена реализация

Обработка программы разделена на несколько компонентов.

### `I.cpp` — точка входа

Главная функция:

1. Запускает измерение времени.
2. Пытается открыть `example.i`.
3. Читает содержимое файла.
4. Передаёт текст лексическому анализатору.
5. Выводит накопленный результат и время выполнения.

Если файл не найден, программа переходит в простой интерактивный режим: приглашение `I>` и обработка введённой строки.

### `Lexer.h` — лексический анализатор

Класс `Lexer` получает исходный текст и разделяет его на токены. Он распознаёт, среди прочего:

- имена;
- ключевые слова;
- названия типов;
- числовые и логические литералы;
- строки в двойных кавычках;
- арифметические и некоторые составные операторы;
- скобки, точку и точку с запятой.

После распознавания токены передаются парсеру.

### `Token.h` — представление токенов

`TokenType` перечисляет категории токенов. Класс `Token` хранит типы и текстовые значения токенов в отдельных векторах.

### `Parser.h` — обработчик инструкций

Класс `Parser` получает токены и обрабатывает инструкцию после получения завершающего токена `;`. В нём находятся обработчики объявлений, присваиваний, `cout` и `cin`.

### `AST.h` — заготовки AST и парсер выражений

В файле объявлены базовые узлы и заготовки для абстрактного синтаксического дерева. Также находится `RecursiveDescentParser`, который вычисляет арифметические выражения методом рекурсивного спуска.

Важно: наличие заготовок AST не означает, что весь исходный код уже преобразуется в полноценное абстрактное синтаксическое дерево.

### `INT.h`, `Split.h` — типы и вспомогательные функции

`INT.h` содержит перечисление `DataType` и шаблонную структуру `Variable`, хранящую значение и тип.

`Split.h` содержит вспомогательные функции для работы со строками, проверки чисел и подготовки контейнеров.

### `Keyword/map.h` и `map.cpp` — таблицы переменных и команд

Здесь объявлены и определены таблицы зарегистрированных переменных, типов и команд. В текущей версии отдельно хранятся целочисленные и логические переменные. Команда `cout` добавляет результат в общий буфер вывода.

### `Erroe.h` — сообщения об ошибках

Содержит функции формирования сообщений о синтаксических ошибках, неизвестных идентификаторах, повторном объявлении и несовместимом типе значения.

## 6. Сборка

В репозитории присутствуют решение Visual Studio `I.sln` и проект `I.vcxproj`.

Для сборки через Visual Studio:

1. Откройте `I.sln`.
2. Выберите конфигурацию сборки и целевую платформу.
3. Выполните **Build Solution**.
4. Запустите полученный исполняемый файл из каталога, в котором доступен `example.i`.

Программа открывает файл с фиксированным именем `example.i`. Поэтому при запуске из другого рабочего каталога файл может не обнаружиться.

Точные требования к версии Visual Studio и стандарту C++ в этой документации не фиксируются: их следует сверить с настройками установленной среды и файла проекта.

## 7. Ограничения текущей версии

Это важный раздел: проект ещё нельзя считать стабильной языковой средой.

- Полноценная система типов пока не завершена. В перечислении типов есть `Float`, `Double`, `CHAR` и `BOOL`, но рабочие обработчики сосредоточены на `int` и `bool`.
- Лексер распознаёт больше конструкций, чем парсер умеет выполнять.
- `if` и `while` присутствуют среди распознаваемых ключевых слов, но полноценное выполнение блоков в показанном обработчике отсутствует.
- Заготовки AST не образуют завершённый конвейер компиляции.
- В текущем `Split.h` функция `split` фактически возвращает исходную строку одним фрагментом; полноценного разделения по точке с запятой в ней нет.
- Обработка ошибок и проверка границ токенов требуют дальнейшей доработки.
- Ввод и вывод реализованы как простые прототипы, а не как законченная стандартная библиотека.

Поэтому примеры следует рассматривать как демонстрацию существующего прототипа. Поведение конструкций, не описанных как реализованные, не гарантируется.
